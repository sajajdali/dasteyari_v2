# بستهٔ تحویل پیاده‌سازی «دست یاری»

نسخه ۱.۰ — همه‌چیزی که برای شروع کدنویسی لازم است.

## این بسته چیست
قالب‌های `.dc.html` **مرجع طراحی** هستند: ظاهر و رفتار نهایی را نشان می‌دهند، ولی کد تولید نیستند.
کار پیاده‌ساز این است: **همان HTML و همان CSS را عیناً به Blade/Livewire منتقل کند** و فقط داده‌ها را داینامیک کند.
سطح طراحی: **hi-fi** — رنگ، تایپوگرافی، فاصله‌ها و حالت‌ها نهایی‌اند. بازطراحی ممنوع.

## شروع در ۶ قدم
1. `laravel new dasteyari` (PHP 8.5 / Laravel 13) + نصب livewire، spatie/laravel-permission، morilog/jalali.
2. `design/assets/*` → `public/assets/` و `design/responsive.css` → `public/css/app.css`. فونت Vazirmatn را self-host کن.
3. فایل‌های `code/` را در مسیر متناظر خودشان کپی کن (ساختار پوشه‌ها یکسان است).
4. `php artisan migrate --seed` — دلایل همه ۲۶ اقدام seed می‌شود.
5. فاز ۱ بستهٔ ۱‑الف را بساز (بخش ۱۰ پلن).
6. برای هر بستهٔ بعدی، الگوی پرامپت بخش ۱۱ پلن را استفاده کن.

## قواعدی که هرگز شکسته نمی‌شوند
هیچ کلاس CSS جدید · هیچ داده hardcode در ویو · مجوز فقط با `@can` · هر اقدام از `ActionModal` · هر تغییر وضعیت یک `case_events` · مبالغ integer · Seeder همراه هر بسته · بدون حذف فیزیکی.
